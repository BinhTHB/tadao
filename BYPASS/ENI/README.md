# 🌸 ENI-PERSONA & ENI-PERSON AUTO INSTALLER 🌸

Bộ cài đặt tự động 1-Click dành cho **Google Antigravity** và **Antigravity IDE**.

---

## 📦 Tính Năng
- Tự động cài đặt 100% bộ kỹ năng `/eni-persona` và `/eni-person` vào Antigravity CLI và Antigravity IDE.
- Tự động cấu hình Global Rules (`~/.gemini/config/rules`).
- Hỗ trợ đầy đủ Windows, macOS, Linux.

---

## 🚀 Hướng Dẫn Sử Dụng
1. Nhấp đúp chuột vào file **`run.bat`** (hoặc `install_eni_persona.bat`).
2. Script sẽ tự động phát hiện Python và tiến hành cài đặt vào Antigravity.
3. Mở Antigravity / Antigravity IDE và gõ:
   - `/eni-persona` hoặc `/eni-person`
